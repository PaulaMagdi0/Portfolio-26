## Task 1 — `features/home/components/Contact.tsx`

Server component (`async`, `getTranslations`).

**Changes:**

1. Pull a second translator scoped to `ui`:
   ```ts
   const tUi = await getTranslations('ui');
   ```
2. Replace literal `data-cursor-label` values:
   - line ~95: `data-cursor-label="open"` → `data-cursor-label={tUi('cursor.open')}`
   - line ~146: `data-cursor-label="top"` → `data-cursor-label={tUi('cursor.top')}`
3. Replace the watermark literal:
   - line ~173: `Paula` (inside `<p>`) → `{tUi('brand.watermark')}`
4. Force LTR on the phone-number `<p>` so the bidi algorithm doesn't reorder `+20 127 776 7028` on the AR layout:
   - line ~78: add `dir="ltr"` to the `<p className="text-ink font-serif ...">` that renders `sec('phoneValue')`.

`feat(i18n): localize Contact cursor labels + watermark + phone dir`

## Task 2 — `features/home/components/WorkRow.tsx`

Client component (`'use client'`, `useTranslations`).

**Changes:**

1. Import locale + digit helper:
   ```ts
   import { useLocale, useTranslations } from 'next-intl';
   import { toLocaleDigits } from '@/lib/digits';
   ```
2. Inside the component:
   ```ts
   const locale = useLocale();
   const indexLabel = toLocaleDigits(String(index + 1).padStart(2, '0'), locale);
   const totalLabel = toLocaleDigits(String(total).padStart(2, '0'), locale);
   ```
3. Replace literal fallbacks in the `cursorLabel` derivation:
   - default: `let cursorLabel = 'CASE STUDY';` → `let cursorLabel = t('ui.cursor.caseStudy');`
   - URL parse catch: `cursorLabel = 'VISIT';` → `cursorLabel = t('ui.cursor.visit');`

The real hostname (when `URL` parses) stays as-is — domain names are not translated.

**Commit:**
`feat(i18n): localize WorkRow cursor labels + index/total digits`
